# Advanced Data Analysis with Pandas 🎮

import pandas as pd

# More Advanced Functions
## 1. Filtering Rows with Conditions 🔍

Filtering lets us ask questions of the data. A condition produces a column of `True`/`False` values (a **boolean mask**), and pandas keeps only the `True` rows.

```py
# Players with more than 50 hours
print(df[df["Hours_Played"] > 50])
```

### Combining Conditions

Use `&` (and) and `|` (or), and put **each condition in brackets**.

```py
# Over 50 hours AND more than 20 missions
print(df[(df["Hours_Played"] > 50) & (df["Missions_Completed"] > 20)])

# Gold OR Platinum rank
print(df[(df["Rank"] == "Gold") | (df["Rank"] == "Platinum")])

# A neater way to check several values
print(df[df["Rank"].isin(["Gold", "Platinum"])])
```

💡 **Note:** _Python's `and` / `or` won't work here. Pandas needs `&` and `|`. Forgetting the brackets is the most common error._

## 2. Selecting with `loc` and `iloc` 🎯

These let us pick rows **and** columns in a single step.

- `loc` selects by **label** (names)
- `iloc` selects by **position** (numbers)

```py
# loc: rows 0 to 2, only two columns
print(df.loc[0:2, ["Gamertag", "Hours_Played"]])

# loc with a condition: Xbox players, showing Gamertag and Cash only
print(df.loc[df["Platform"] == "Xbox Series X", ["Gamertag", "In_Game_Cash"]])

# iloc: first 3 rows, first 2 columns
print(df.iloc[0:3, 0:2])
```

💡 **Note:** _`loc` includes the end of the range (0:2 gives three rows), but `iloc` stops before it (0:3 gives three rows). Why do you think that is?_

## 3. Creating Calculated Columns 🆕

Let's measure how _efficient_ each player is.

```py
# Cash earned per hour played
df["Cash_Per_Hour"] = (df["In_Game_Cash"] / df["Hours_Played"]).round(2)

# Missions completed per hour
df["Missions_Per_Hour"] = (df["Missions_Completed"] / df["Hours_Played"]).round(2)

print(df[["Gamertag", "Cash_Per_Hour", "Missions_Per_Hour"]])
```

💡 **Note:** _`.round(2)` tidies decimals to 2 places. Who earns the most per hour? Who completes missions fastest?_

## 4. Grouping Data into Categories 🏷️

Sometimes we want to turn numbers into labelled groups. `pd.cut()` sorts values into **bins**.

```py
# Bins: 0-39 = Casual, 40-69 = Regular, 70+ = Hardcore
df["Playtime_Band"] = pd.cut(
    df["Hours_Played"],
    bins=[0, 40, 70, float("inf")],
    labels=["Casual", "Regular", "Hardcore"],
    right=False,   # include the lower edge, exclude the upper
)

print(df[["Gamertag", "Hours_Played", "Playtime_Band"]])
```

### Using a function with `apply()`

We can also write our own rule and apply it to every row in a column.

```py
def cash_status(cash):
    if cash >= 300000:
        return "Rich"
    elif cash >= 100000:
        return "Comfortable"
    else:
        return "Broke"

df["Wealth"] = df["In_Game_Cash"].apply(cash_status)
print(df[["Gamertag", "In_Game_Cash", "Wealth"]])
```

## 5. Summarising with `groupby` 📊

`groupby` splits the data into groups, then calculates something for each group.

```py
# Average hours played on each platform
print(df.groupby("Platform")["Hours_Played"].mean())

# Several statistics at once with agg()
summary = df.groupby("Platform").agg(
    Players=("Gamertag", "count"),
    Avg_Hours=("Hours_Played", "mean"),
    Avg_Missions=("Missions_Completed", "mean"),
    Total_Cash=("In_Game_Cash", "sum"),
)
print(summary)
```

💡 **Note:** _`agg()` with named columns lets you label each result as you create it, which makes the output much easier to read._

## 6. Counting and Correlation 🔗

```py
# How many players on each platform?
print(df["Platform"].value_counts())

# Is there a relationship between hours played and cash?
print(df["Hours_Played"].corr(df["In_Game_Cash"]))

# Correlation between all numeric columns
print(df.select_dtypes("number").corr().round(2))
```

💡 **Note:** 

- _A correlation close to **1** means the two columns rise together, close to **0** means no relationship, and close to **-1** means one rises as the other falls._ 

- _Does playing more hours really cause more cash, or could something else be going on?_

---

## 7. Sorting by Multiple Columns 🔀

```py
# Sort by Platform first, then by Hours (highest first) within each platform
print(df.sort_values(by=["Platform", "Hours_Played"], ascending=[True, False]))

# Find the single best player for a stat
best = df.loc[df["Missions_Completed"].idxmax(), "Gamertag"]
print(f"Most missions completed: {best}")

# The top 3 by cash
print(df.nlargest(3, "In_Game_Cash")[["Gamertag", "In_Game_Cash"]])
```

💡 **Note:** _`ascending=[True, False]` lets you choose a direction for each column. `nlargest()` is a shortcut for sort then `head()`._

## 8. Visualising Data 📈

Charts make patterns obvious at a glance. Pandas works with `matplotlib` to draw them.

```py
import matplotlib.pyplot as plt

# Bar chart: cash by player
df.plot(kind="bar", x="Gamertag", y="In_Game_Cash", legend=False)
plt.title("In-Game Cash by Player")
plt.ylabel("Cash ($)")
plt.tight_layout()
plt.show()

# Scatter plot: do more hours mean more cash?
df.plot(kind="scatter", x="Hours_Played", y="In_Game_Cash")
plt.title("Hours Played vs Cash")
plt.show()
```
